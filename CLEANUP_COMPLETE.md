## Next Steps / Recommendations

### Before Development
1. **Start frontend dev server**
   ```bash
   cd apps/web
   npm run dev
   ```

2. **Start backend dev server**
   ```bash
   cd apps/backend
   npm run dev
   ```

3. **Generate Prisma types**
   ```bash
   npx prisma generate
   ```

4. **Set up database**
   ```bash
   npx prisma migrate dev --name init
   ```

## Key Decisions Documented

- **Monorepo structure**: npm workspaces chosen for simplicity and native npm support
- **Shared package location**: `packages/shared/` for clear separation
- **Database schema location**: Monorepo root (`prisma/`) since it's shared by all apps
- **Configuration files**: Each app has its own config; root only has workspace config
- **Duplicate removal strategy**: Keep only `index.ts` files to prevent confusion and ensure single source of truth
